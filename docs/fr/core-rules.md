# Core Rules

Cette page accueillera les règles communes à toutes les déclinaisons de **Truchements**.

Le socle actuel est volontairement petit : ce qui compte dans une situation, l'échelle Matière / Humain / Agent / Puissance, les Prismes liés à cette échelle et la règle encore en développement autour des manifestations sur un 6.

Les règles détaillées sont encore en cours de conception.
